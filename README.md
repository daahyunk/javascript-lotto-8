# javascript-lotto-precourse
## 프로젝트 개요

간단한 로또 발매기를 구현한다.
사용자는 금액을 입력해 로또를 구입하고,
당첨 번호 및 보너스 번호를 입력해 당첨 결과와 수익률을 확인할 수 있다.

---

## 구현 목표

객체 간 협력을 통해 로또 발매 및 결과 계산을 수행한다.
* 클래스와 함수를 분리해 하나의 클래스가 한 가지 역할만 수행하도록 설계한다.
* UI 로직(입출력)을 제외한 모든 로직은 단위 테스트로 검증한다.
* 하드 코딩을 지양하고 상수 파일을 통해 값을 관리한다.
* README 기능 목록을 지속적으로 업데이트하며, 정상 케이스와 예외 케이스를 모두 정리한다.

## 기능 목록

### 1. 구입 금액 입력

* [x] 사용자로부터 로또 구입 금액을 입력받는다.
* [x] 구입 금액은 1,000원 단위로 나누어 떨어져야 한다.
* [x] 구입 금액은 0보다 커야 하며 숫자여야 한다.
* [x] 예외 상황 발생 시 `[ERROR]`로 시작하는 메시지를 출력하고 해당 단계부터 재입력받는다.

  * [x] 입력값이 숫자가 아닌 경우 → `[ERROR] 구입 금액은 숫자여야 합니다.`
  * [x] 입력값이 0 이하인 경우 → `[ERROR] 구입 금액은 0보다 커야 합니다.`
  * [x] 1,000원 단위로 나누어 떨어지지 않는 경우 → `[ERROR] 구입 금액은 1,000원 단위여야 합니다.`


### 2. 로또 발행

* [x] 구입 금액에 따라 구매 가능한 로또 개수를 계산한다.
  (ex. 8000원 입력 -> 8개 구매)
* [x] 각 로또는 1~45 사이의 중복되지 않은 6개의 번호로 구성된다.
* [x] 발행된 로또 번호는 오름차순으로 정렬한다.
* [x] 번호가 6개가 아닌 경우 → `[ERROR] 로또 번호는 6개여야 합니다.`
* [x] 번호가 중복된 경우 → `[ERROR] 로또 번호는 중복될 수 없습니다.`

### 3. 발행 결과 출력

* [ ] 구입한 로또 수량과 각 로또 번호를 출력한다.

```
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
...
```

### 4. 당첨 번호 입력

* [ ] 쉼표(,)로 구분된 6개의 숫자를 입력받는다.
* [ ] 숫자는 1~45 사이의 값이어야 하며, 중복되지 않아야 한다.
* [ ] 예외: 개수가 6개가 아니거나 범위를 벗어나거나 중복된 경우 `[ERROR] 당첨 번호 형식이 올바르지 않습니다.` 출력 후 재입력.

### 5. 보너스 번호 입력

* [ ] 1개의 보너스 번호를 입력받는다.
* [ ] 보너스 번호는 당첨 번호와 중복될 수 없다.
* [ ] 예외: 1~45 범위를 벗어나거나 당첨 번호와 중복될 경우 `[ERROR] 보너스 번호가 올바르지 않습니다.` 출력 후 재입력.

### 6. 당첨 결과 계산

* [ ] 각 로또의 번호를 당첨 번호와 비교하여 일치 개수를 계산한다.
* [ ] 일치 개수 및 보너스 번호 여부에 따라 등수를 판별한다.

| 순위 | 조건                | 상금             |
| -- | ----------------- | -------------- |
| 1등 | 6개 번호 일치          | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원    |
| 3등 | 5개 번호 일치          | 1,500,000원     |
| 4등 | 4개 번호 일치          | 50,000원        |
| 5등 | 3개 번호 일치          | 5,000원         |

* [ ] 등수 계산은 `LottoRank`(enum 객체)를 통해 관리한다.

### 7. 당첨 통계 출력

* [ ] 등수별 당첨 개수를 출력한다.
* [ ] 총 수익률을 계산하여 소수점 둘째 자리에서 반올림한다.
* [ ] 예시 출력:

```
당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

## 예외 처리 원칙

* [ ] 모든 예외 메시지는 `[ERROR]`로 시작한다.
* [ ] 잘못된 입력 발생 시 해당 부분부터 다시 입력받는다.
* [ ] 프로그램 종료 시 `process.exit()`를 사용하지 않는다.
